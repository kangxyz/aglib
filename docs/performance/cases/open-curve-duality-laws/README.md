## Lossless change-patch encoding

The exact source changes are stored as UTF-8 JSON text for
[native compact rows](native-compact-rows/change.patch.json),
[whole-arrow transport](whole-arrow-predicate/change.patch.json) and
[variable original flip](variable-original-flip/change.patch.json). Each
records its original relative path and SHA-256. Decode and verify either
file with the following command, replacing `FILE.json`:

```sh
python3 -c 'import hashlib,json,sys; d=json.load(open(sys.argv[1])); b=d["text"].encode(d["encoding"]); assert hashlib.sha256(b).hexdigest()==d["original_sha256"]; sys.stdout.buffer.write(b)' FILE.json > original-file
```

The case checksum manifest binds the published encodings; each JSON field
binds the corresponding exact original patch bytes.
