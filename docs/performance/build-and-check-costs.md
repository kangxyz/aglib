## Keep the dependency graph aligned with actual consumers

Place a genuinely independent interface in a focused leaf and import that
owner directly. A stable H0 interface need not depend on unrelated H1 proofs.
Independent chart producers can be compiled before a costly concrete
specialization. Batch necessary changes to widely imported providers before
rebuilding their actual affected closure.

The [H0/H1 separation](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#separate-the-structural-h0-interface-from-its-h1-consumer)
unblocked UnitTrace while the distinct H1 target still failed. It established
a passed lower interface and a reachable consumer body, not a complete UnitTrace
pass or a measured whole-proof speedup.

When separate parallel target graphs share an unresolved prerequisite, both can
compile it before a reusable output exists. In the recorded relative-duality
integration, two full graphs repeated `Relative.AffineTrace`; restricting the
second worker to its missing canonical model-chart branch avoided that overlap.
Partition the pending closures when this actual conflict occurs; parallel work
itself is optional.
[Original overlap observation](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#late-lint-repairs-and-dependency-invalidation).

A new sibling file or an importer count is not required for every lemma.
Choose a natural mathematical owner with an actual consumer; preserve compatible
outputs rather than rebuilding a whole package after a move or merge.

## Producer and consumer cost

An abstraction can make a producer cheaper while transferring work to callers.
The rejected `Modules.Scalars.Open` factory saved about 9.94 seconds of producer
CPU but added 10.22 in its measured caller. The retained `Map.Open` constructor
improved its measured producer/caller pair while slowing some individual callers.
[Original comparisons and retained interfaces](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#whole-library-pass).

Keep the actual component formulas and affected in-package consumers in view.
A separate client build or benchmark is not a routine prerequisite. When a
comparison is requested, state the scope that was measured and avoid
extrapolating a local saving to the whole library.

## Reuse outputs and checker setup

Native source/import/compiler/options determine whether a restored artifact
can be reused. A cache candidate is not current lint or axiom evidence.
Preserve successful compatible check categories and fill actual failures or
coverage gaps through the existing native entry.

A failed outer graph can contain an unchanged successful module frontend.
Conversely, a green dependent `Ran` row in the recorded failed no-build graph
could be blocked: count actual successful outputs, not display labels.
[Original cache-progress observation](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#failed-cache-probes-and-progress).

Repeated environment imports can dominate checker startup; even one command
can load an environment repeatedly for its arguments. Use the existing package
batch/root command with its actual selection and exclusions. A missing checker
executable calls for its matching tool dependency, not a clean mathematical
rebuild. Current native declaration lint is owned by the development guide.

The old [lint-memory observations](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#declaration-lint-memory-in-ci)
and [selected-origin observations](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#historical-selected-origin-lint-measurements)
measured different environment-loading patterns. Their separate-driver,
Test-umbrella, client and control sequences are historical scope, not present
workflow instructions; their checker predicates are not interchangeable.
Motivic's [compiled-checker case](https://github.com/kangxyz/motivic/blob/main/docs/performance/local-cases.md#compiled-checker-startup)
illustrates a launch failure distinct from a source-style finding.

## Interpret resource failures at the right level

Distinguish frontend memory, frontend threads, concurrent compiler jobs,
aggregate RSS/cgroup limits and the runner reserve. A serialized tail cannot
use spare compiler slots. A local pass with a larger allowance does not
establish CI-budget fit. Low-memory failures can also produce misleading
secondary type errors.

The [resource-calibration record](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#remote-resource-calibration-on-the-unchanged-library)
tested unchanged sources under different limits and thread counts. It does not
establish a universal optimal profile. Preserve the admitted profile and consult
the current operating owner; frontend `-M` is a limit, not preallocated RAM,
and summed RSS can count shared pages more than once.

## Distinguish cache, observer and checker failures

Root-only export omits dependency outputs; Build/Test transport must also
recover the required unpublished dependency leaves. Current cache and workflow
owners describe that handoff.
[Original bounded transport evidence](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#test-dependency-handoff-and-native-resource-limits).

Shared-artifact ctime can change when hardlink counts change while bytes remain
the same. The current native observer rechecks content for those changes and
retains actual identity/content protections. Quillen's older-pin private-reflink
workaround is a historical preparation result, not a routine preparation step.
[Observer repair](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#local-validation-and-shared-artifact-link-metadata),
[Quillen historical case](https://github.com/kangxyz/quillen-k-theory/blob/main/docs/performance/local-cases.md#historical-hardlink-workaround).

A cache-record failure is distinct from a checker failure or successful check.
Resolve the concrete source/artifact basis, then use the documented continuation;
do not interpret this distinction as permission to ignore a failed guard.

Generated import-only entries use the generator's explicit `longFile 0`
exemption. Ordinary implementation limits retain their own policy.
[Original generated-entry case](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#generated-import-entries-and-file-length-limits).
Likewise, cached compilation provides no fresh coverage of a command linter
that did not execute; see Motivic's [header case](https://github.com/kangxyz/motivic/blob/main/docs/performance/local-cases.md#cached-command-lint-coverage).

## Preserve import and exposure boundaries

Use the exact casing in the pinned source tree. The recorded `ULift` import
worked on macOS while Linux required the actual `Ulift` filename.
A local instance still has a declaration name; distinct modules can collide
when imported together even when each compiles alone.

Expose only the implementation boundary required by the real API. A module-wide
exposed section can make private helper names unavailable and cause elaboration
cascades. Export needed component equations rather than using blanket
`import all` or changing global transparency.
[Import casing](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#preserve-exact-import-casing-across-native-platforms),
[local-instance names](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#local-instance-names-must-remain-distinct-across-actual-imports),
[exposure repair](https://github.com/kangxyz/aglib/blob/d578d2cb686c84187b76dc5f51a2de4b3a41df63/docs/PERFORMANCE.md#limit-exposure-to-the-actual-public-implementation-boundary).

A provider pass may only unblock a still-failing consumer. Keep that boundary
attached to its recorded result instead of turning it into a current status claim.
