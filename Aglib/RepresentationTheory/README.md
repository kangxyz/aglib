# Equivariant quotients

`EquivariantQuotients` owns
`RepresentationTheory.EquivariantQuotients.EquivariantAddHom` and
`EquivariantAddEquiv`, with the actual additive group actions. Stable kernels,
quotient actions, marked quotient equivalences and change of marking retain
their original equivariance and surjectivity assumptions.

The canonical objects are Mathlib's additive homomorphisms, additive
equivalences and quotient additive groups. Current consumers are finite cyclic
character algebra and pointed finite-etale coefficient theory.
