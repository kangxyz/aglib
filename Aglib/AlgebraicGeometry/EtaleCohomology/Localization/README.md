# Open and closed localization

These leaves retain the original lower-shriek counit and inverse-image unit
on the actual small-etale site. Point lifts, original geometric stalk maps
and complementary open/closed ranges supply short exactness; it is not a
field of an assumed localization package.

The abelian and genuine constant-ring module sequences have separate native
coefficient owners. `ModuleComplex` applies the actual module sequence to
bounded-below complexes and uses the existing native `triangleOfSESPlus`.
The resulting triangle retains its original incidence, quotient and cone
connecting map. Its comparison with the separately derived composite
functors remains a distinct consumer, not an implicit renaming of objects.

Current acceptance and uncompiled consumers are recorded with exact source
hashes and ordinary native receipts. A draft or source declaration alone is
not a completed localization result.

## Unbounded native localization

`UnboundedComplex` applies the same proved module-sheaf sequence degreewise to
arbitrary integer cochain complexes. It uses Mathlib's native `triangleOfSES`
and its actual mapping-cone connecting map; it is not a bounded-below argument.

`UnboundedComparison` identifies the first vertex using the exact open
localization factors and the third vertex using the original unbounded closed
direct-image unit. Existing closed-image exactness proves that unit invertible.
The comparison equations identify the original chain counit and unit with the
installed unbounded adjunction maps, naturally in every complex morphism.

`Unbounded` descends the actual triangle functor through `DerivedCategory.Q`.
Its normalized triangle has vertices `j! j* K`, `K`, and `Ri_* i* K`, with the
original unbounded counit and unit as its first two arrows. Its third arrow is
the transported native connecting map, and distinguishedness and functoriality
hold for every native derived object. Independent derived-category universes
are retained. This construction requires complementary open/closed immersions,
not boundedness, torsion, finite cohomological dimension, or proper base change.
It does not assert compactification independence or the remaining exceptional
base-change and composition calculus.
