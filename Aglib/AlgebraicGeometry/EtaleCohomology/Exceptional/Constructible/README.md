# Constructible exceptional direct images

[FinitePresentationFunctors](FinitePresentationFunctors.lean) gives the
exceptional direct image on bounded-below and bounded constructible complexes
for separated, quasi-compact, locally finitely presented morphisms over
quasi-compact quasi-separated bases. The coefficient ring is left Noetherian
and is annihilated by a positive integer. The forgetful comparison identifies
these functors with the original exceptional direct image.
[FinitePresentationBaseLocal](FinitePresentationBaseLocal.lean) gives bounded
constructibility on each quasi-compact quasi-separated base restriction.
