# Constructible constant-ring module coefficients

This family uses the native `Sheaf X.smallEtaleTopology (ModuleCat R)` category
in the original value universe. A local constant value is a finitely generated
`R`-module. Its additive group is not assumed finite. The coefficient ring is
commutative and unital; its universe is independent of the scheme universe.

## Focused imports and public interfaces

- `ZMod` is an independent adapter for the original finite-abelian predicate.
  `isFiniteLocallyConstant_zmodSheaf_iff` and
  `isConstructible_zmodSheaf_iff` use the original
  `TorsionZMod.sheafUnderlyingIso`. `zmodSheafMap_underlying` retains the
  literal original coefficient arrow. `exists_zmodSheaf_of_isConstructible`
  gives a positive modulus and an actual module lift on a qcqs scheme.
- `Images` fixes `ModuleSheaf`, `moduleUnderlying`, `moduleInverseImage` and
  `moduleDirectImage` as native site functors. The underlying, composition,
  constant and adjunction comparisons use the original constructions.
  The actual module inverse image preserves finite limits for every scheme
  morphism, without a torsion or properness condition.
- `LocallyConstant` defines `FiniteTypeLocalTrivialization` and
  `IsFiniteTypeLocallyConstant` using actual jointly surjective etale charts,
  `Module.Finite` values and module-valued trivializations. It proves
  isomorphism invariance, constant coefficients, and arbitrary scheme
  pullback. Over a finite coefficient ring, the same charts give the original
  finite-abelian local-constancy predicate after scalar forgetting.
- `Basic` defines `ConstructiblePartition` by extending the existing
  `FiniteLocallyClosedPartition`, with module inverse-image restrictions.
  `IsConstructible` is the same affine-local finite-stratum condition with
  finite-type module values. It proves isomorphism invariance, constructibility
  of finite-type locally constant coefficients and constant finite modules,
  and the original underlying implication over finite rings.
- `ZModLocallyConstant` proves `isFiniteTypeLocallyConstant_zmod_iff` for
  positive modulus. For the reverse implication it replaces each finite
  additive chart value `A` by the native `cokernel (n • 𝟙 A)`. Its constant
  sheaf is unchanged because the given coefficient is annihilated by `n`.
  This also handles empty charts, where vanishing of a constant sheaf map
  does not force vanishing on its additive value.
- `ZModComparison` proves `isConstructible_zmod_iff` for positive modulus,
  preserving the same affine opens, strata and immersions. It also proves
  `isConstructible_canonicalZModSheaf_iff` and
  `exists_constructible_zmodSheaf`, so the canonical bounded lift is genuinely
  constructible as a module-valued sheaf.

## Lower owners and original maps

`Algebra/Category/ModuleCat/Sheaf/ConstantCoefficients` supplies standard-size
native sheafification and the original constant-forgetting comparison for an
arbitrary ring. `ConstantImages` supplies the native Kan-extension and
sheafification comparison for inverse image, its coefficient naturality, and
flat inverse-image exactness. `ModuleCat/FullForget` proves fullness of scalar
forgetting for any ring generated by its integer casts. `Grp/ZModQuotient`
constructs the genuine module on the original additive cokernel and proves its
finiteness when the original additive value is finite.

These ordinary sheaves can use the already published constant-presheaf and
ringed-module equivalences in `Sites/Torsion/ZMod/Ringed/Equivalence`. The
original module cohomology/Ext bridges remain in
`Sites/SheafCohomology/ModuleCoefficients`; this family does not introduce a
second cohomology object or action.

## Accepted closure

`ClosureConstructibleSums` proves finite categorical sums/products for the
actual affine-local constructible module predicate over any commutative ring.
`ClosureConstructible` proves kernels, cokernels and extensions over a
Noetherian coefficient ring, through the original refined charts and upstream
common partitions. This is weak-Serre closure, not arbitrary ambient subobject
or quotient closure. The same local-system closure is in `ClosureProperties`.
See [the closure proof note](CLOSURE.md) for the actual finite-presentation,
finite-generator and original extension-cokernel arguments.

## Accepted pullback and Zariski locality

`PullbackAffine`, `PullbackLocality` and `Pullback` prove arbitrary constructible
module inverse image over any commutative coefficient ring. There is no
quasi-compactness or separation hypothesis on the original morphism. On a
qcqs scheme the affine-local definition supplies an actual global finite
partition; the proof uses native geometric open-partition gluing with the
original stratum factorization maps. `DescentOpen` proves descent along any
actual Zariski open cover, with no cover-finiteness or ambient qcqs premise.

`GenericTrivialization` constructs actual finite Galois constant
trivializations over field spectra. `GenericTrivializationDense` gives a dense
affine open and an actual finite-etale surjective trivialization on an integral
scheme. The prescribed finite module remains a native module in the original
value universe. `GenericTrivializationFixedValue` refines an actual nonempty
finite-etale trivialization to a connected Galois one while retaining its
literal supplied module value. No finite additive-group or Noetherian-ring
premise is used in these results. `GenericTrivializationDenseGalois` combines
these into the actual dense-open connected Galois trivialization, retaining
the literal original finite module value. `DescentEtale` descends local
constancy on the actual base changes of an explicitly supplied common
partition; it does not manufacture such a partition from unrelated upstairs
partitions or assert unrestricted etale descent by itself.

`DescentEtaleConstructible` now proves unrestricted descent along any jointly
surjective etale family over arbitrary schemes and commutative coefficient
rings, with independent scalar universe. The actual downstairs partition is
produced by finite/clopen geometric refinement and reduced-source factorization
through the original upstairs strata. `EtaleClopenPartition` retains the
original whole-source restriction maps in this argument. No Noetherian-base,
small-ring, finite-underlying-group or supplied-common-partition assumption
is inserted in the final arbitrary-cover theorem.

## Accepted finite-etale direct image

`FiniteEtaleProduct` constructs the actual coefficient-linear local product
comparison from the original split-cover restriction fan. Its projection
equation retains literal section restrictions, without assuming scalar
forgetting is full. `FiniteEtaleImage` proves that the original module direct
image along any finite-etale morphism preserves finite-type local constancy
and constructibility. The coefficient ring is arbitrary commutative with
independent universe, and neither the base nor cover has an added qcqs or
Noetherian hypothesis. Variable rank and empty fibres are included. The proof
reuses the native local splitting and accepted arbitrary etale descent; it
does not depend on the pending general finite module base-change wrapper.

The separate geometry-facing `ModuleCoefficients/FiniteBaseChange` now proves
ordinary finite base change for the original module mate, for arbitrary finite
morphisms and independent-universe constant-ring coefficients. Its
`BaseChangeMap` supplier identifies the exact original abelian exchange after
native scalar forgetting. This is not finite-ffp constructibility or full PBC.

## Mathematical boundaries

The positive-ZMod comparison is a comparison with the existing abelian
predicate, not a replacement for it. At modulus zero the reverse implication
from finite abelian local values remains valid, but finite generation over the
integer ring does not imply finite additive cardinality.

The family does not yet assert general module finite-presentation descent,
general surjective qcqs descent, finite finitely presented direct-image
constructibility, or the constructibility consequence of extension by zero.
Those require their remaining actual descent, finite-image and
extension-by-zero suppliers. Nor does this family assert proper base change
or smooth base change. Actual constant-module cohomology finiteness is owned
by the separate Finiteness family. The existence of a local trivialization does not supply those results.

## Original Galois subobjects and action maps

`GaloisTrivialSubobject` realizes fixed-image maps from original constant modules, with exact original pullback, monicity, native short exact cokernel and same-cover quotient trivialization. `GaloisActionMaps` proves the corresponding original deck-action naturality and quotient-projection equivariance. These are not an arbitrary representation-object descent equivalence. The accepted `Finiteness/PGroupModuleSheaves` consumer uses these exact suppliers for actual characteristic-p p-group-trivialized proper cohomology finiteness.

## Actual field and Artin sections

`FieldSections` proves the original constant-unit isomorphism over separably
closed fields for arbitrary module values, without torsion, and finite
sections for constructible modules there. `SigmaSections` and `ArtinSections`
retain the original finite-component restrictions, nilpotent residue maps and
actual finite product of sections. `DimensionZero` proves genuine original
module H0 finiteness on proper dimension-zero schemes over separably closed
fields, for arbitrary commutative coefficient rings and independent Ext
universes. `Finiteness/DimensionZeroModules` combines that result with original
positive-degree vanishing for all-degree finite generation in dimension zero.
No general finite-fp image-constructibility or D localization premise is used.
