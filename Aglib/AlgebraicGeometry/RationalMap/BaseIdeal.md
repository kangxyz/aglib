# Denominator and base ideals of original rational coordinates

[BaseIdeal.lean](BaseIdeal.lean) starts with the original integral scheme
and a finite tuple in its original function field. The actual regular
module embeds in the actual generic pushforward. Pulling back its finite
product along the original multiplier row constructs simultaneous actual
numerators and denominators. Multiplication by zero is included.

The denominator projection is monic. The generic inclusion is affine,
so the generic pushforward and finite pullback are quasicoherent. The
native image-ideal construction gives the actual denominator ideal; its
canonical module is the native kernel module of its closed subscheme.
The original relation module identifies with that actual ideal module.

The base ideal is the native image ideal of the finite numerator row.
Each original coordinate has an actual module-linear factor into its
kernel module. Its composite with the original structure-module embedding
and generic inclusion is the original denominator map followed by
multiplication by the specified function. The corresponding section and
stalk identities use the original coefficient maps into the same function
field. Under Noetherianity these quasicoherent submodules of the structure
module are coherent.

On each nonempty actual affine open, the denominator comparison is the
original fractional-ideal denominator of the original finite coordinate
span. The actual kernel-section equivalence has forward map the original
ideal inclusion. Through it, every original numerator is the canonical
linear numerator over that same affine ring. The base ideal is the
intrinsic integral product of the denominator and the original fractional
span. Empty affine opens have their unique zero-ring ideals separately;
no algebra map from that zero ring to the function field is introduced.
No fractional-ideal formula is asserted for arbitrary nonaffine global
sections.

The native coproduct of the original coordinate maps is epimorphic through
affine-basis section surjectivity, with the same index set and maps.
No global-section surjectivity on arbitrary nonaffine opens is used.
If an original coordinate is one, its numerator is the original
inclusion, the denominator ideal lies in the base ideal, and both ideal
sheaves are nonzero. Nonvanishing of denominator stalks itself does not
need that distinguished coordinate or regularity.

The stalk comparisons use the original affine germs. A common denominator
in the proof expresses the affine denominator as a colon by a finitely
generated numerator ideal. Native localization of that colon gives the
original local-ring denominator. The native range-localization theorem,
applied to the original numerator equations and actual ideal map, gives
the corresponding base-ideal comparison. No chart, denominator or stalk model family is an input.

For regular actual stalks, the proved all-dimensional regular-local
factorial theorem supplies the nonzero principal denominator. Its actual
singleton bases and the native stalk-kernel comparison give local rank one
of the actual denominator kernel module. This requires local
Noetherianity, integrality and an original coordinate one, and has no
ambient dimension bound or supplied UFD-family premise.

Primitivity of the original normalized numerators excludes containment of
any base-ideal stalk in a proper principal ideal. At actual stalk dimension
at most one the base ideal is the unit ideal. In dimension two the actual
nonmaximal prime ideals are principal, so every prime above the base ideal
is maximal. The original Noetherian local quotient is consequently
Artinian and has finite length. Over a globally Noetherian scheme with
actual stalk dimensions at most two, the proper lower ideal-sheaf
Artinian theorem and compactness of the original closed immersion give an
actual Artinian quotient subscheme. Finite colength is a conclusion.

These are the scopes of the authored proofs. Native compilation and
independent mathematical adoption are recorded separately; a pending
source is not a successful invocation. No projective presentation,
principalization sequence or invertibility of the base ideal is assumed
or asserted here.
