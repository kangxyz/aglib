# Polynomial and Laurent affine geometry

[PolynomialLaurent](PolynomialLaurent/README.md) contains actual spectra, relative base-product diagrams, the Laurent coordinate unit and polynomial zero section. Algebra coefficient maps and their natural squares remain in the lower polynomial/Laurent owner.

These are general affine-space and coefficient constructions on ordinary schemes. Their origin in application charts introduces no projective-line, degree, curve or K-theory application object.
