# Original module stalk embedding in the original function field

`fromSpecStalkGenericFrame` transports one supplied frame of the original
generic stalk using the actual pullback-stalk comparison and native
extension-of-scalars unit object. Its pullback-unit germ equation is explicit.
`stalkToFunctionField` then composes the accepted original local-spectrum
sections comparison, accepted affine generic-germ map and inverse original
function-field equivalence. Every original neighbourhood germ has the value
of that SAME supplied frame at the original generic germ.

The construction and value laws require only an integral scheme X, an actual
point x, a module sheaf M and that original generic frame. Injectivity adds
quasicoherence of M and genuine torsion-freeness of the original stalk M_x;
torsion-freeness of actual local-spectrum top sections is derived through
the original sections/stalk isomorphism. No finite, normal, Noetherian,
local-base, dimension, rank-one or new localization-model input is used.

This is the generic lower consumer for canonical specialization. It does not
choose another generic frame or numerator, nor prove a modification theorem.
