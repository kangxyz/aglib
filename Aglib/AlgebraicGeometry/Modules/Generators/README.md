# Open-free generators and finite local lifting

[OpenFreeFunctor](OpenFreeFunctor.lean), imported as `Aglib.AlgebraicGeometry.Modules.Generators.OpenFreeFunctor`, constructs actual open-free module sheaves and their functor of opens. `openFreeHomEquiv` represents actual sections, with naturality in both coefficient sheaves and opens. [OpenFreeStalk](OpenFreeStalk.lean) compares actual stalks with the free stalk module on point-membership data and proves the original comparison naturality.

[LocalLifting](LocalLifting.lean) gives `Scheme.Modules.exists_finite_local_lifts`: for an actual locally surjective map, finitely many sections admit simultaneous lifts on one neighborhood. Finiteness of the family permits a common neighborhood. The actual [epimorphism/local-surjectivity](../../../Algebra/Category/ModuleCat/Sheaf/Epimorphisms.lean) result supplies that hypothesis for module-sheaf epimorphisms.

[GlobalSections](GlobalSections.lean), imported as `Aglib.AlgebraicGeometry.Modules.Generators.GlobalSections`, writes global sections as morphisms `𝟙_ ⟶ M` out of the monoidal unit. `globalSectionsEval M` evaluates all of them, and `M` is generated by its global sections when it is an epimorphism. A morphism through which every global section factors is then an epimorphism (`epi_of_unitHom_factor`), and a morphism surjective on global sections lets every global section of its target factor (`exists_unitHom_factor_of_surjective`, through `unitHomGlobalSectionsEquiv`). Finitely many maps jointly surjective on global sections carry generating global sections to generating global sections (`epi_sigmaDesc_globalSectionsEval_comp`, `exists_finite_sections_comp`). A finite family `s` with `Sigma.desc s` an epimorphism gives Mathlib's `∃ σ : M.GeneratingSections, σ.IsFiniteType` (`exists_generatingSections_isFiniteType_of_epi`). Its consumer is the global generation of regular twists in [Regularity](../../Cohomology/Projective/Regularity/README.md).

Focused imports are these four leaves. [Local splitting of vector bundles](../LocallyFree/README.md), flat generators and scheme injective Cech exactness use these real section/stalk maps. No global basis or projectivity assumption is inferred from a local lift.
