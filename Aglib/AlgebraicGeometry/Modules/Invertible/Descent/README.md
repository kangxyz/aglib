# Binary descent for invertible modules

| Source | Reusable interface |
| --- | --- |
| [Square](Square.lean) | Square-zero comparison data for line bundles and their actual pullbacks. |
| [OverIso](OverIso.lean) | Descent comparison along an isomorphism of the specified overlap. |
| [Limit](Limit.lean) | The limit-stage interface used by the formal system construction. |

The sources retain the given maps, overlap identifications and transition
isomorphisms. Their hypotheses are part of the interfaces; the leaves are not
standalone unconditional Picard-lifting theorems.
