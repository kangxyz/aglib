# The original cross relations of a generating line-bundle row

Let X be any native scheme, let L be an actual LineBundle X, and let
π : O_X^ι → L.val be the original row from the native free module sheaf.
The construction uses the actual categorical kernel F = kernel π and the
original tensor functor. It accepts no presentation or generation of F ⊗ L
as input. There are no field, Noetherian, completeness, properness, normality,
or flatness hypotheses on X.

The public generatingKernelSection L π i j is a morphism O_X → F ⊗ L.
The typed abbreviation generatingRowInclusion X i is the original native
free inclusion SheafOfModules.ιFree i; it introduces no new basis or model.
The theorem generatingKernelSection_ι identifies its composite with the
original tensor of kernel.ι π as

    (λ_O)^(-1) ≫ (e_i ⊗ (e_j ≫ π) - e_j ⊗ (e_i ≫ π)).

Thus this is precisely e_i ⊗ s_j - e_j ⊗ s_i for the original basis and
the original sections s_i = e_i ≫ π. The unit isomorphism only identifies
O_X with O_X ⊗ O_X; it does not change the row, kernel, or coefficient map.

The definition first lifts the actual dual relation

    s_j^* ≫ e_i - s_i^* ≫ e_j

through the actual kernel. The public generatingKernelRelation_comp proves
that its composite with the same π is zero, and generatingKernelDualRelation
is this canonical kernel lift. These are the data and equation used by the
public tensor-section construction. Tensoring that lift with L and
precomposing with the inverse of the actual dualEvaluationIso produces the
section above. The proof of its tensor formula checks the actual evaluation
on pure tensor sections. On each genuine line chart the scalar identity
ell(m) n = ell(n) m follows because m and n are multiples of the same
generator; sheaf separation retains the identity on the original open.

The public generatingKernelMap L π has source the original free sheaf on
the ordered pairs ι × ι, with exactly these component morphisms. If ι is
finite and the original π is epic, generatingKernelMap_epi proves that
this map is epic. The epi assumption is solely the generation of L by
the original row.

Generation is proved on actual local line charts. Native finite-basis
lifting gives a local right inverse to the original row. In a frame,
write its coefficients as a_i and the right-inverse coefficients as b_i,
so that Σ_i b_i a_i = 1. For an actual kernel vector z with coefficients
z_i, the explicit finite identity is

    z = Σ_i Σ_j z_i b_j (a_j e_i - a_i e_j).

The second sum vanishes because Σ_i z_i a_i = 0. This calculation is made
for the original mapped inclusions, projections, kernel inclusion and
dual sections, in an abstract preadditive category to avoid unfolding the
concrete sheaf implementations. It remains valid for zero rings, empty
opens, empty schemes, and an empty finite index type. There is no global
chosen nonzero coefficient, coefficient field, or supplied global splitting.
The local epi result is transported through the original over-site/open
restriction comparison and sheaf separation. Finally exact tensoring by the
actual line bundle, the finite-coproduct comparison, and the actual dual
evaluation isomorphism identify its source with O_X^(ι × ι).

The mathematical source is [Stacks Project, Lemma 27.13.9, tag 0B3B](https://stacks.math.columbia.edu/tag/0B3B).
Its scope is an arbitrary scheme and an invertible module generated by a
finite family of global sections. The proof here retains the actual finite
row, actual kernel, and original tensor-inclusion equation needed by the
maximal-ideal blowup section-algebra consumer in R.R2. This file does not
construct a normalization, prove a power-section identity, or prove normality
of a blowup.
