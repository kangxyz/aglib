# Finite type of the actual relative differential sheaf

For the original morphism `f : X -> Spec Lambda` and an affine open
immersion `j : Spec R -> X`, the coefficient map is exactly
`Spec.preimage (j >> f)`. The original differential restriction,
structural-map congruence, and affine comparison identify the actual
restricted relative differential sheaf with the tilde of the Kähler
module for this coefficient map.

The exported differential equation preserves the original localized
`d(b)` on every principal open. It uses the original inverse section
map of `j`, so the scalar action and the differential normalization
remain those of the original composite.

If `f` is locally of finite type, the actual affine coefficient map is
of finite type. Its algebraic Kähler module is finite, and the original
tilde comparison proves that `relativeDifferentialSheaf f` is
affine-locally quasicoherent of finite type. This conclusion does not
require a Noetherian scheme. On a locally Noetherian source it is the
coherent-sheaf condition. No unrestricted coherence claim is made over
non-Noetherian schemes.

The current consumer is the determinant of relative differentials on
an actual regular surface-point blowup. Its finite-type input comes
from the original finite coefficient expansion and actual finite-type
blowups. A generic differential basis, its rank, and determinant-line
invertibility are separate conclusions. This family assumes neither
smoothness, perfectness, separable residue fields, nor freeness of the
raw differential module.
