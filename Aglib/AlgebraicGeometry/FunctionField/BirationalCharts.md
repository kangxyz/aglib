# Function fields and affine charts of a birational model

For an integral model with its original dominant birational map to an affine domain, the supplied fraction field is compared with the actual function field through the inverse of that same function-field map. Nonempty affine chart maps preserve the original coefficients, restrictions and scalar towers. Extension maps retain both supplied fields and their original algebra maps. Concrete normalization-cover algebra structures are supplied separately by the cover adapter.
