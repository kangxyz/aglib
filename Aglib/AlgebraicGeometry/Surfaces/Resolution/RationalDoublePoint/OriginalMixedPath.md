# Actual mixed-case marking and external-base contradiction

API: [exists_marked_original_tail](OriginalMixedPath.lean#L33), [exists_regular_original_point_of_initial_cone_of_complete_base](OriginalMixedPath.lean#L178).

## Initial full cone

`exists_marked_original_tail` uses the original `ClosedPointBlowupPath`,
a normal Nagata dimension-two initial stalk satisfying
`NormalModificationH1Vanishing`, and a supplied generating triple with a
nonzero homogeneous quadratic generating its entire canonical cone kernel.
It assumes every selected stalk nonregular and constructs a native marked
tail. `OriginalPathCones` derives every later cone and surface property.

## Constructed marking

If some original stage is Case I, the next real singular point selects a
good original parameter. The first actual successor produces minimality,
so the marking starts at its child. A local dependent recursion carries
only the genuine chosen generators/polynomial and their proved properties;
each successor supplies the original scalar-parameter, centre and residue
identities. These fill exactly the existing native `Marking` fields.

If there is no Case-I stage, the unique full-cone classifier constructs actual
Case-II data at every stage. First entry and then, if necessary, second entry
produce a full marker at stage 0, 1 or 2. The second entry retains
`f(t)=f(u)*r` and the previous centre generated by `f(u)`, not by `r`.
The existing full-marker continuation then constructs a native marked tail.

## Earlier complete base

`exists_regular_original_point_of_initial_cone_of_complete_base` takes
the same initial cone and geometry, without the everywhere-singular premise.
It additionally accepts a local injective map from a commutative local
domain `A`, complete for its maximal ideal and of dimension two, with finite
original residue extension. No Noetherianity of `A` is added.
At the constructed tail, it composes that same map with the actual
finite-prefix scalar map. Native residue-map composition and prefix residue
finiteness give the exact finite extension required by the existing complete-
base marking theorem. Neither the initial path stalk nor any later stalk is
assumed complete.

## Limits

The regular-point endpoint gives `∃ n, IsRegularLocalRing (P.localRing n)`.
`FiniteHeight` combines this contradiction with the finite-prefix branching
theorem and native König. The finite global-chain and normalized-terminal
consumers use the same original point maps and proved normal stages.
