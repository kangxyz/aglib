# Generic points under surjective morphisms

[GenericPoint](GenericPoint.lean) proves
`Scheme.map_genericPoint_of_surjective` for actual surjective morphisms between
irreducible schemes. No reducedness, integrality, finiteness, properness,
Noetherianity or dimension hypothesis is imposed. The source hash is recorded
in the leaf; finite-curve projectivity is an immediate consumer.
