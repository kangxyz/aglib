# Scheme-valued base-change diagrams

[Coefficients](Coefficients/README.md) owns actual schemes over `Spec R`,
algebras in `Under R` with the stated opposite variance, and their fibre-product
scheme diagrams. The over-scheme is arbitrary and need not be affine. The
construction uses the actual pullback, projections and coefficient-induced
scheme maps, with identity and naturality equations on those same maps.

Polynomial/Laurent specializations use the lower
[algebra coefficient diagrams](../../Algebra/Polynomial/Laurent/README.md) and
[spectrum constructions](../Spec/PolynomialLaurent/README.md). Compactness and
quasi-separatedness transport retain the original scheme's stated properties.
No field, Noetherian or fixed-dimension premise is imposed merely to construct
the coefficient family.

Actual module-sheaf adjunction-mate comparisons have their own
[module base-change](../Modules/BaseChange/README.md) owner. Conditions for an
invertible module comparison remain attached to that interface.
