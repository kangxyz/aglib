# Original R1 vanishing above a maximal model

[R1.lean](R1.lean) proves the cohomological consequence of the actual
maximal-H1 construction over a complete normal local surface. The endpoint
is `AlgebraicGeometry.Scheme.Cohomology.exists_normal_model_original_R1_vanishing`.

Its inputs are a complete Noetherian local domain A, integral closedness
of A, dimension A equal to two, and the genuine previous theorem input
`NormalModificationH1Bounded A`. It returns an integral normal X and an
actual proper dominant f:X→Spec A whose original function-field map is an
isomorphism. For every actual normal integral proper birational g:Y→X it
proves

```lean
IsZero (((Scheme.Modules.pushforward g).rightDerived 1).obj
  (FiniteTraceCoordinates.structureModule Y))
```

The actual maximal model comes from `exists_maximal_normalModification`.
No source-dimension bound, exceptional set, R1 vanishing, rationality,
resolution, or cohomology isomorphism is supplied by the caller.

The source dimension is derived first. Completeness and the base dimension
give the Nagata property of A. For each nonempty affine open U of the actual
model, its original scalar map `affineBaseMap f U` is finite type, injective,
and algebraic. The original germ equation and the original birational
function-field map prove these facts. The public GF2 dimension theorem
bounds the original chart ring Γ(X,U) by two. The actual affine-open cover
then gives `topologicalKrullDim X ≤ 2`; empty opens are handled separately.

`original_model_H2_subsingleton_of_complete_surface` applies the native
complete-base cohomology theorem to the original structure module. That
theorem bounds the actual closed fibre by one and uses the original
thickenings and formal-functions comparison. H2(X,O_X)=0 is consequently
derived from the genuine model data.

The existing `moduleBirationalLeray_exact_of_complete_surface` supplies the
original-unit short exact sequence. Its edge comparison identifies the
third term with actual global sections of the displayed R1. Its first-map
comparison identifies the first arrow with exactly

```lean
moduleCohomologyMapAlongLinear g (FiniteTraceCoordinates.structureScalar f)
  (SheafOfModules.unitToPushforwardObjUnit g.toRingCatSheafHom) 1
```

The maximal-model theorem makes this particular map surjective. Exactness
and surjectivity of the actual edge then force every global R1 section to
be zero. All source and target actions are the original structural actions.
The Leray argument uses no assumed relative R1 or R2 vanishing.

The sheaf support is derived independently. A proper birational map to the
normal Noetherian surface X is an isomorphism on an actual open with finite
closed complement. The native higher-direct-image restriction comparison
and affine quasicoherent acyclicity show that the same R1 restricts to zero
there. Proper coherence proves that this original R1 is coherent.

Finite closed support makes zero global sections detect the sheaf. The
native additive H0 comparison identifies H0 with the product of the
supporting stalks. The finite set is enumerated by an actual finite natural
index, including the empty case. Evaluation at one coordinate shows each
supporting stalk is zero, and the actual module-stalk criterion gives
`IsZero` of the original R1 sheaf.

The public intermediate interfaces separate the derived dimension and H2
statements, actual coherent finite closed support, zero original R1
sections, and zero R1 itself. The lower H1-surjectivity hypothesis is
discharged in the endpoint by the actual maximal-model theorem.

This is a global higher-direct-image assertion. Universal vanishing for
arbitrary modifications of a stalk still needs proper local replacement
with an original pullback square and the actual flat-localization
cohomology comparison. This module does not assert rational stalks, a
rational-model classification, local resolutions, or full resolution.
