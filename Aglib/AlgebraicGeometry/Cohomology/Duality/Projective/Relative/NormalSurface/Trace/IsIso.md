# Isomorphism of the original canonical trace

Source: [IsIso.lean](IsIso.lean).

The first detection theorem uses actual finite sums of strictly negative twists
presenting the target and coherent kernel. Vector-bundle Hom bijectivity then
proves epimorphy and monomorphy in the original module-sheaf category.

This is a prerequisite, not a canonical-trace isomorphism oracle. The geometric consumer proves Hom bijectivity from the original derived
structure-unit isomorphism via the native projection formula, original
pullback/pushforward adjunction and coherent Serre duality. The final theorem
therefore asserts invertibility of the original canonical trace under that
original structure-unit hypothesis. All projective embeddings, base triangles,
normality, dimension bounds and generic finiteness hypotheses are retained.
