# Native single and affine transports for curve Serre duality

This provider retains the native fully faithful shifted preimage, the actual single and Q normalizations, and the original affine/global-sections coefficient isomorphisms. Its module-valued map uses the original composition and unit comparisons. The concrete curve pairing is a later consumer.

Integer reindexing is retained as an actual degree and equality proof on
both sides. The Q comparison and native single/homology identifications are
proved through their original component theorems. Native zero-degree homology
and the associator of the actual composite functor are explicit; none is
assumed definitionally identical to another model.
