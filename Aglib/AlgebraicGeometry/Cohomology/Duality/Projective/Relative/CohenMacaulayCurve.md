# Chosen-embedding concentration for a possibly nonreduced CM curve

Let k be an arbitrary field and let j:C→P^n_k be an actual closed immersion,
with the finite coordinate set identified with Fin(n+1). The concentration
input is the following elementary condition on the **actual closed stalks**:

For every closed x∈C there is b∈m_x which is a nonzerodivisor on O_(C,x),
and the radical of its principal ideal is m_x.

This is an explicit regular-parameter condition, not a predicate containing
the desired Ext or derived concentration conclusion. A projective pure
one-dimensional Cohen–Macaulay curve supplies it, including nonreduced and
non-Gorenstein curves. Deriving that condition from a future general CM
predicate is outside this file. The proof itself needs only the displayed
condition and the actual closed embedding.

The field need not be perfect. No reducedness, geometric reducedness,
normality, integrality, smoothness, separability, Gorenstein condition or
invertibility of the canonical module is assumed.

## Closed-stalk calculation

Fix a closed point x of C. Its image under the closed immersion is closed
in projective space. Pull it back to an original polynomial chart in n
variables. The corresponding prime is maximal. The native maximal-height
theorem over arbitrary fields gives dimension n for the actual polynomial
stalk, and that stalk is regular local without a separability hypothesis.

The actual affine quotient chart supplies a surjective local map S→B
from this ambient stalk to the original source stalk in the chart. The
open-immersion stalk isomorphism transports the supplied regular parameter
from O_(C,x) to B. Lift its value b through S→B to a∈m_S. The action of a
on the restricted S-module B is exactly multiplication by b. Hence [a]
is weakly regular on that original module.

The principal ideal generated by b has maximal radical. The existing
`isFiniteLength_quotient_ofList_of_radical_eq_maximalIdeal` derives finite
length over S of B/aB, using the actual finite local quotient action.
`IsRegularLocalRing.subsingleton_ext_of_regular_sequence`, which is an
arbitrary-module theorem, then gives Ext_S^q(B,S)=0 whenever q+1≠n.
It assumes neither normality nor a domain structure on B.

The native quotient-chart derived stalk Ext equivalence compares this
Ext group with the original derived homology stalk. Its coefficient is
identified with S only through the genuine Euler top-differential frame,
which already contains the original coefficient-unit normalization. The
source and coefficient Ext transports are the original degree-zero Yoneda
maps. No new Ext size or A-action is assigned to an abstract group.

## Global concentration and canonical normalization

The existing FiniteSource.Derived theorem proves finite presentation and
closed ordinary stalk support for each original homology sheaf. The actual
projective source is compact. If a homology sheaf had nonempty support, its
closed support would contain a closed point. The preceding calculation
rules this out in every nonnegative degree except n−1. Negative homology
already vanishes for the original injective-resolution model.

`cmCurveHomology_isZero` therefore proves concentration in integer degree
n−1. `cmCurveDualizingObject_isGE` and `_isLE` express the two bounds on the
same object. `cmCurveCanonicalIso` is precisely the native
`DerivedCategory.Plus.isoSingleHomology` reconstruction:

`Rj!(Omega[0]) ≅ single_C(n−1, W_C)`.

`cmCurveCanonicalIso_homology` states that this comparison induces the
identity on the original H^(n−1), after the installed single/homology
isomorphism. Thus the canonical module and its comparison are not freely
chosen. `cmCurveTopDifferentialCanonicalIso` names the raw top-differential
coefficient using only the original unit isomorphism and this same
normalized canonical module.

No separate positivity input on n is required for this integer statement.
For a genuine nonempty pure curve the regular-parameter condition is
incompatible with ambient dimension zero. The empty case and n=0 do not
force a fabricated natural-number codimension into the theorem.

## Consumer boundary

This file covers the unit base coefficient k only. An arbitrary finite
coefficient line V, its comparison with a surface dualizing coefficient,
canonical base change, the reindexed Serre pairings and their Yoneda
naturality, and the actual Cartier boundary/counit normalization remain
separate obligations. In particular no full canonical-generation, RDP,
Grauert–Riemenschneider or resolution theorem follows from this concentration
module alone.
