# Rerooting the same original prefixes

`Reroot.lean` separates the first actual child from a finite history by one
recursive native sigma equivalence. It does not define another history or
blowup model. Every prefix remains in `Type u`; equality of the original
endpoint scheme and point accompanies the equivalence.

`prepend` is its inverse at a fixed first child. The original first-child
fibre equivalence, injectivity, parent compatibility and every truncation
law derive from that single construction. The length-one truncation is
exactly the original selected first child. Eligibility is arbitrary, but
children retain their actual global closedness and original image equation.
No abstract invariance premise is added.

`prepend_datum_map_square` retains the actual native blowdown maps with only
endpoint equality transports. `prepend_pointLocalRingMap_square` gives the
corresponding equality of literal original local-ring arrows, including the
transported actual source point and its proved target-point equation.

The intended later use is strict decrease of a genuinely proved finite
height: a child prefix of length n gives a parent prefix of length n+1.
This leaf proves no finiteness, König application, height, marking, regular
iterate, or termination theorem. It requires no geometric assumptions beyond
the data already stored in the original child type.
