# Original centre-twisted pullback line

For a commutative ring `R`, an actual ideal `I`, and an original line bundle
`L` on `Spec R`, `centreTwistedPullbackLine I L` is exactly the tensor of
the original blowdown pullback of `L` with the dual of `centreIdealLine I`.
The underlying-module law is literal reflexivity. There are no domain,
Noetherian, local, regular-sequence, chart, or trace hypotheses.

This is a single named construction for the existing target, not a new
model or an additional comparison premise. The exact new leaf passed its normal native check in graph186.
