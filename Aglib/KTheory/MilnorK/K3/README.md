# Degree-3 tensor presentation

`MilnorK.K3.Group F` is the retained tensor/Steinberg presentation of degree
3. Its symbols, field maps and residue calculations belong to `MilnorK.K3`.
The uniform public group is `MilnorK.K F 3`; `CompatibilityK3` constructs
the symbol-preserving inverse comparison. There is one implementation of each
presentation and no top-level `MilnorK3` declaration namespace.

The precise characteristic, valuation, uniformizer and reduction conditions
remain on each theorem. These modules do not supply a Quillen comparison.
