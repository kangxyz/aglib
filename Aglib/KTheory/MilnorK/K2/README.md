# Degree-2 tensor presentation

`MilnorK.K2.Group F` is the retained tensor/Steinberg presentation of degree
2. Its symbols, field maps and residue calculations belong to `MilnorK.K2`.
The uniform public group is `MilnorK.K F 2`; `CompatibilityK2` constructs
the symbol-preserving inverse comparison. There is one implementation of each
presentation and no top-level `MilnorK2` declaration namespace.

The precise characteristic, valuation, uniformizer and reduction conditions
remain on each theorem. These modules do not supply a Quillen comparison.
