# Polynomial Milnor norms

`Basic` constructs the norm for a monic irreducible polynomial on the actual
root-field Milnor groups. Degree filtrations, stage lifts and rational residues
supply the construction. `Independence` compares actual presentations; the
`Complete*`, `DVR*`, `Rational*` and branch leaves give the stated completion,
valuation and scalar-extension comparisons used by finite-extension norms.

Each theorem keeps its original characteristic, irreducibility, finiteness,
uniformizer and scalar-square hypotheses. Import individual leaves rather
than this proof family merely to obtain a symbol or a field restriction map.
