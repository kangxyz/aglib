# Milnor norms

[Polynomial](Polynomial/README.md) constructs norms from actual monic irreducible
root-field presentations. [Finite extensions](FiniteExtension/README.md) transports
them to the original finite extension and proves presentation independence and
tower transitivity. These are maps of the existing `MilnorK.K` groups.

The optional `Aglib.KTheory.MilnorK.Norms` entry imports the finite-extension
tower theorem. The basic symbol facade does not load the full norm proof graph.
