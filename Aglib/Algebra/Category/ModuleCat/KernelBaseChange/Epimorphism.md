# Surjectivity of the actual extended kernel map

`ModuleCat.extendedKernelMap_epi_of_ker_eq_map` concerns an original
commutative square of ring maps. If the actual target kernel is the ideal
extension of the actual original kernel, the canonical
`extendedKernelMap` is an epimorphism. No flatness, Noetherianity,
surjectivity of either original quotient map, or choice of generators is
required. The native categories use their displayed common universe.

`extendedKernelMap_one_tmul` identifies each original kernel generator
with the image of its literal unit tensor. The linear image therefore
contains the entire ideal generated by those original images. The proof
uses the actual kernel inclusions and scalar-extension adjunction.

The current geometric consumer is the canonical pullback map for a closed
immersion along an arbitrary scheme morphism. Its target ideal is the
actual inverse-image ideal. This epimorphism does not identify a nonflat
pullback of an ideal module with that inverse-image ideal; a kernel can
remain in the canonical map.
