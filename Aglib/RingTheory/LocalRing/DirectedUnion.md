# Directed unions of the original local subrings

Import `Aglib.RingTheory.LocalRing.DirectedUnion`.
The current consumer is the marked ordinary point-blowup path in
`AlgebraicGeometry.Blowup.Arc.MarkedPath`. That consumer embeds the original path stalks
compatibly in their same actual function field. Their ranges form
an increasing sequence in Mathlib's native `LocalSubring` domination order.
This order records both the subring inclusion and locality of that inclusion.

`LocalSubring.directedUnion S hS` has underlying subring exactly
`sup_n (S n).toSubring` in the supplied field. Locality is proved: every
union element belongs to one stage, where it or its complement is a unit.
`DirectedUnion.exists_stage` retains an actual stage representative, and
`inclusion` is the literal original subring inclusion.

`inclusion_isLocal` proves that a stage nonunit cannot become a unit in the
union. An alleged inverse belongs to another stage. Moving both elements
to a common later stage would make the original element a unit there,
contradicting locality of the original domination map. No Noetherianity,
separatedness, or completion theorem is used in this argument.

Let `p` belong to the maximal ideal of the initial stage and suppose the
original stage inclusions satisfy

```text
map (maximalIdeal (S n)) (S n → S (n+1))
  = span {the original image of p in S (n+1)}.
```

`stageMarker` and `marker` are those literal inclusion images of `p`.
`maximalIdeal_eq_span` proves that the union's maximal ideal is generated by
the same `marker`. A union nonunit is represented by a stage nonunit and
becomes divisible by the marker at the next original stage.
If `p` is nonzero, `marker_mem_nonZeroDivisors` proves that this actual union
marker is a nonzerodivisor, because the union is a subring of the same field.
The union itself is not asserted Noetherian, separated, or a DVR.

`residueMap_bijective` uses surjectivity of the actual initial-to-stage
residue-field maps and proves bijectivity of the residue map induced by
the original initial-stage inclusion into the union. Its proof chooses a
stage for an actual union representative and applies the original residue
map there. It introduces no chosen residue marking or field extension.

`Completion` is the literal
`AdicCompletion (span {marker}) (DirectedUnion.Ring S hS)`.
The module reuses the published
`AdicCompletion.PrincipalDiscreteValuationRing` provider, with the proved
union maximal-ideal equality and nonzerodivisor. It does not introduce a
second generic principal-completion theorem. The resulting statements are
`completion_isLocalRing`, `completion_isAdicComplete`, `completion_isDomain`,
`completion_isDiscreteValuationRing`, and `completion_marker_irreducible`.
Domainness is derived and bound explicitly in the DVR conclusion.

`stageMap` is the original stage inclusion followed by the same native
completion algebra map. `stageMap_comp` and `stageMap_marker` retain the
original composition and parameter equations. `stageMap_isLocal` derives
locality of every stage map. `stageMap_residue_bijective` identifies the
actual initial-stage residue map to this completion, using the same original
coefficient map and the published completion residue comparison.

The [upper marked-path construction](../../AlgebraicGeometry/Blowup/Arc/MarkedPath.md)
supplies the function-field embeddings of the scheme stalks, extends the
original starting-ring map to its own completion, proves that extension
surjective, and compares the given scheme path with the completed-base arc
path. Normality and dimension of the original starting completion remain
explicit conditions of its general termination interface, with separate
complete-base corollaries. No arc or desired geometric sequence is an
input to the present union construction.
