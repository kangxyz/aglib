# Finite-type integer algebras and generated subrings

`FiniteResidue` proves that a field of finite type over the integers is finite,
that all maximal quotients of a finite-type integer algebra are finite, and
that a nontrivial such algebra has an actual surjective map to a finite field
in the same universe. Nontriviality is retained for the existence statements.

`Subring` restricts actual units using membership of both value and inverse,
and proves finite type of a subring generated by finite data in a field.
`SubringLift` gives the literal inclusion for extra finite data and proves
restriction and element-lifting formulas from a supplied lift. These support
finite-relation descent; no geometric spreading theorem is supplied.
