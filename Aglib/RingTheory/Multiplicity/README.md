# Scalar-length multiplicities

[PrincipalEuler](PrincipalEuler/README.md) forms integer expressions from actual scalar kernel/cokernel lengths and proves additivity, filtration and local associativity with explicit finite scalar-homology inputs. Its lower subjects are generic scalar homology, prime filtrations, support and canonical localization length.

These are general module/ring results. Their origin in cycle computations introduces no cycle object, principal-face equality or K-theory comparison into this library.
