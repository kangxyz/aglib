# Normal local quotients and finite injective dimension

Let `q : P → S` be a surjective local map, with `P` regular local and `S`
a normal Noetherian local domain. Assume `dim S = r ≤ 2` and
`dim P = n+r`.

`subsingleton_ext_of_normal_quotient_codimension` specializes the existing
normal-quotient concentration theorem to the actual restricted source
module and an arbitrary supplied Ext universe. It does not assume that
the kernel of `q` is generated by a regular sequence.

`coinducedHomology_hasInjectiveDimensionLE` proves that the actual
`S`-module `H^n(R coind_q P)` has native injective dimension at most `r`.
Its proof applies concentrated derived adjunction to every native
`Shrink (S/I)` source in quotient Baer. Each restricted source is finite
over `P` by surjectivity; the existing finite-module projective dimension
bound therefore kills the ambient Ext in degree `r+1+n`.

`coinducedHomology_hasInjectiveDimensionLE_of_iso` transports the bound
for any actual ambient coefficient frame `N ≅ P`, through the unchanged
derived-coinduction homology map. Thus an actual local frame of a geometric
coefficient line suffices; no definitional identification of that line with
the ring is asserted.

`self_hasInjectiveDimensionLE_of_coinducedHomology_linearEquiv` transports
this bound through an actual `S`-linear trivialization to the regular
`S`-module. No new Gorenstein predicate is defined. The converse from
finite self-injective dimension to a frame of the same selected canonical
module is proved in [NormalQuotientCanonical](NormalQuotientCanonical.md),
using the original homothety and finite-projective-dimension construction.
Neither completeness nor finiteness over an earlier Cohen base is assumed here.
