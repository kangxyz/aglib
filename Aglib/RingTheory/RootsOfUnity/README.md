# Root-generated finite unramified algebras

[Adjoin](Adjoin.lean), imported as `Aglib.RingTheory.RootsOfUnity.Adjoin`, owns `Algebra.RootsOfUnity.RootAlgebra`: the literal subalgebra of a specified commutative `R`-algebra generated by `ζ`. Its distinguished `root` retains the equation `ζ ^ n = 1`.

`rootAlgebra_finite` requires `n ≠ 0`. With both `n ≠ 0` and `IsUnit (n : R)`, `rootEtaleSurjection` is the actual standard-etale presentation map and `rootAlgebra_formallyUnramified` proves formal unramifiedness of this subalgebra. The root equation is retained throughout.

The prerequisites are actual adjoining, integrality and standard-etale algebras. No valuation, local-ring, completeness or residue-field assumption is imposed. Original roots-extension applications remain external consumers of this generic constructed algebra.

[FiniteCharacter](FiniteCharacter.lean) constructs the finite cyclotomic
character of the actual absolute Galois group. Its chosen-root construction
retains the supplied primitive root; the characteristic-zero, positive-level
endpoint chooses that root and proves independence and continuity. It supplies
the root-action comparison in the fundamental-group field family.

The Galois, BaseField, PrimitiveCoordinates, Reduction, Inclusion and Exactness
leaves use `Field.absoluteGaloisGroup.RootsOfUnity.Mu`, the additive form of the
actual roots in the fixed algebraic closure, with their discrete continuous
Galois action. Power reduction, literal inclusion and compatible field embeddings
act on that same carrier. Coordinates and CyclotomicCoordinates use the existing
finite cyclotomic character and retain characteristic zero and positive levels
at their chosen-root endpoints; CoordinateLevels keeps actual compatible roots
and canonical ZMod reduction. FieldEmbedding delegates to the native field
fundamental-group root embedding. No second root module or H1 quotient is defined.
