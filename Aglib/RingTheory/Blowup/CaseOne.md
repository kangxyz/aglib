# The conditional local chart core for Case I

The companion `CaseOne.lean` proves the conditional local statement:
a singular localization of the actual saturated blowup chart, with its actual
coordinate-compatible exceptional quotient, has the original plane equation in
the square of the original plane-point ideal. In Case I this forces bijectivity
of the original induced residue homomorphism. The same original exceptional
element generates the extended centre and remains outside the child maximal
ideal squared.

This module takes the coordinate-compatible exceptional quotient as input;
[QuadraticPresentation](QuadraticPresentation.md) constructs it from the
full canonical tangent-cone kernel and its stated Hilbert-function inputs.
This conditional local core does not complete Case I or the general
resolution theorem.

## Objects and exact hypotheses

Let `A` be a commutative local ring, `t : maximalIdeal A`, and
`g : Fin 2 → maximalIdeal A`. Put `k = ResidueField A`,
`P = MvPolynomial (Fin 2) k`, and let `Q : P` be the original dehomogenized
quadratic. The chart is literally

```
C = Localization.Away.saturatedChart A (maximalIdeal A) (t : A).
```

Thus it is the subalgebra of `A[1/t]` generated by the original fractions from
the original maximal ideal. Its exceptional ideal is the principal ideal of
the original image of `t`.

`CaseOne.Presentation A t g Q` consists of an actual ring equivalence
`C/(t) ≃ P/(Q)` and two displayed laws:

- each original coefficient `a : A` maps to the constant `residue A a`;
- each original fraction `g i / t` maps to the original variable `X i`.

It contains no regularity, square-membership, dimension, residue-rationality,
or tangent-independence conclusion. It presents the exceptional quotient only;
it does not present the ambient chart as a hypersurface. Producing this exact
object from the canonical full quadratic kernel remains a load-bearing upstream
obligation.

For a maximal ideal `M : Ideal P` containing `Q`, the file constructs the
surjection `point : C → P/M`, its literal kernel `prime`, and the literal prime
localization `LocalRing = Localization.AtPrime prime`. Its native ring, algebra,
and localization instances are named explicitly so that every ideal and quotient
uses the same ring structure. This remains the literal native localization type.
The local map from `A` is the original coefficient map through `C`. The equations `prime_eq_comap`
and `prime_comap_base` identify the actual primes before any residue-rationality
conclusion.

The singularity and dimension statements require `A` to be Noetherian and a
domain, and require the original denominator `t` to be nonzero. Noetherianity
and the domain property of the chart and child are derived. Dimension two and
minimality additionally require `Q ≠ 0`. The residue-bijection endpoint further
requires `Q.totalDegree ≤ 2` and the literal Case-I affine condition

```
¬ ∃ c : k, c ≠ 0 ∧ ∃ l : P,
  l.totalDegree ≤ 1 ∧ Q = MvPolynomial.C c * l ^ 2.
```

The later homogeneous-cone consumer must derive this condition for its chosen
actual dehomogenization. There is no perfectness, separability, equal
characteristic, finite p-rank, or coefficient-field-section assumption.

## Construction and proof

`localizedQuotientEquiv` localizes an actual quotient equivalence at the
corresponding original primes. It uses the native localization-of-a-quotient
instances and the original images of the prime-complement submonoids.
`localQuotientEquiv` specializes it to

```
LocalRing/(parameter) ≃ (Localization.AtPrime M)/(Q).
```

Its coefficient and fraction lemmas preserve the original equations. The
parameter is definitionally the original local map applied to `t`.

The actual plane localization is regular of dimension two. Its dimension is
proved by regrouping the two polynomial variables, contracting a maximal ideal
to the one-variable PID, and applying the native height theorem. This argument
uses the actual ideal and does not assume its residue field is separable.

`equation_mem_sq_of_not_regular` argues contrapositively. If `Q ∉ M²`, the native
contraction formula for powers of the maximal ideal gives that the original
localized equation is a regular parameter in the plane localization. Its
quotient is regular. The actual localized quotient equivalence therefore makes
the quotient of the actual child by its original parameter regular. The
parameter is a nonzerodivisor, derived from the original domain and `t ≠ 0`.
The native principal-quotient regularity-lifting theorem makes the child regular,
contradicting its actual singularity. Thus the endpoint derives `Q ∈ M²`; it
does not take that conclusion as a premise.

`local_dimension` uses the dimension-one plane quotient, the exact quotient
comparison, and the two principal-quotient dimension inequalities. It derives
dimension two for the child. `maximalIdeal_generated_by_parameter` lifts two
actual regular-plane maximal-ideal generators through that quotient. The native
Nakayama lemma in `MarkedChart` then proves `parameter_not_mem_sq` for a singular
child. This is a separate argument from regularity lifting. The `centre` lemma
identifies the extension of the original maximal ideal with the principal ideal
of that same original parameter.

Finally, the `QuadraticClosedPoint` theorem shows that the actual field
`P/M` has degree one over its original constant-field action. The comparison
`residueEquiv` is constructed from the original surjection `C → P/M`, before
using Case I. The lemma `residue_map_comparison` states literally that this
comparison composed with `IsLocalRing.ResidueField.map localMap` is the original
constant map `k → P/M`. The endpoint `residue_map_bijective` proves bijectivity
of that original induced residue homomorphism.

## Smallest consumer

The next geometric consumer should supply `Presentation` from the full canonical
quadratic kernel and the actual saturated-chart/dehomogenization maps. It must
retain the coefficient and original-fraction equations, prove nonvanishing and
the Case-I affine condition for the actual `Q`, and identify its selected
closed chart point with the displayed prime. It can then apply
`equation_mem_sq_of_not_regular`, `local_dimension`, `centre`,
`parameter_not_mem_sq`, and `residue_map_bijective` directly.

Uniqueness of a singular point, preservation of Case I under continuation,
the chosen good coordinate in subsequent charts, and global marked-path
assembly are not supplied by this file. Genuine upstream rationality,
Gorenstein, normal ordinary-blowup, full-Hilbert, and completion/arc conditions
remain with their respective suppliers. No termination result is duplicated.
