# Arc maps, relation division, and actual generic local rings

The focused import is `Aglib.RingTheory.Blowup.ArcTermination`. Its declarations
belong to `Localization.Away` and use the existing `saturatedChart` subalgebra
of the original principal localization. The current consumer is the arc
termination obligation R.D3 in the general surface resolution proof.

For `f : C →+* R`, the centre `arcCenterIdeal f t` is `(t) + ker f` and
`arcChart f t` is the literal saturated chart of that ideal in `C[1/t]`.
The original ring `C` is the coefficient ring. For each `z : ker f`,
`arcFraction f t z` is the actual fraction `z/t` in this chart, and multiplying
it by the image of `t` recovers the original image of `z`.

Assume `R` is a domain and `f t ≠ 0`. The construction `arcMap f t ht` maps
this chart to the original `R`. It first uses the induced map
`C[1/t] → R[1/f(t)]` and proves that the entire chart has image in the embedded
copy of `R`; injectivity of `R → R[1/f(t)]` then gives the displayed map.
`arcMap_base` keeps the original `f` on `C`, and `arcMap_surjective` derives
surjectivity from surjectivity of `f`.

`ker_arcMap` identifies its exact kernel with the ideal generated by all
`z/t`, for `z ∈ ker f`. The generating-family version `ker_arcMap_eq_span`
retains a specified original family whose ideal span is `ker f`.
No kernel-identification premise is assumed.

`map_ker_sq_eq_exceptional_sq_mul_ker_sq` proves the genuine ideal equality

```text
((ker f)²) · chart = (t²) · (ker arcMap)².
```

For an actual relation

```text
tⁿ z − a tᵐ w ∈ (ker f)²,       n > 0, m > 0,
```

`transformed_relation_mem_ker_sq` proves

```text
tⁿ⁻¹ (z/t) − a tᵐ⁻¹ (w/t) ∈ (ker arcMap)².
```

It obtains an element of the squared chart kernel from the ideal equality
and cancels the actual exceptional square in the saturated chart. The
coefficient `a` can be arbitrary. The one-term torsion relation is supplied
by `transformed_torsion_relation_mem_ker_sq`.

If `R` is local, `arcClosedPoint` is the actual preimage of its maximal ideal.
For surjective `f`, it is maximal. If `f t` generates the maximal ideal of `R`,
its equations are the image of `t` together with the divided kernel.
For a surjection of local rings, `arcCenterIdeal_eq_maximalIdeal` proves
that the original centre is the original maximal ideal of `C`.

`arcLocalRing` is the native localization at `arcClosedPoint` and
`arcLocalMap` is its constructed map to the same `R`. The exact original base
map is `arcLocalBase`, and its composite with `arcLocalMap` is `f`.
`ker_arcLocalMap` proves extension of the chart kernel under this localization;
`ker_arcLocalMap_eq_span` keeps the same specified divided generators.
`local_transformed_relation_mem_ker_sq` carries the displayed relation to this
actual local ring.

`saturatedChart_span_eq_adjoin_fractions` identifies the actual algebra
generators for a displayed ideal span. Finite generation of the centre then
proves `arcChart_isNoetherian` and `arcLocalRing_isNoetherian` over a
Noetherian original ring.

`arcChart_exists_denominator` retains the literal equation `x t^n = c`
inside the chart. `arcChart_ringHom_ext_of_exceptional_isUnit` proves that
maps which invert the actual exceptional parameter are determined by their
original scalar map.

`arcChartToGeneric` restricts the native principal-localization lift to the
original `C_p`, where `p = ker f`. If the actual arc image of a chart element
is nonzero, its denominator equation proves its image in `C_p` is a unit.
This derives the unit conditions for `arcLocalToGeneric` on the actual
closed-point local ring and for `arcGenericInverse` on its localization at
`ker arcLocalMap`.

`comap_ker_arcLocalMap` derives the exact pullback of the new kernel to the
original `p`. Thus `arcGenericMap` is Mathlib's native `localRingHom` on the
original `arcLocalBase`. Its two compositions with `arcGenericInverse` are
proved to be the identity by localization uniqueness and the actual chart
uniqueness result. `arcGenericEquiv` is the resulting canonical equivalence
from the original `C_p` to the actual generic local ring of `arcLocalRing`;
`arcGenericEquiv_toRingHom` fixes its forward map exactly.

The new generic ring is a regular named type whose underlying type is the
literal native prime localization. Its exposed `CommRing`, algebra,
localization, and local-ring instances all use that original localization.
The chart uniqueness argument requires only a semiring target. These shared
structures keep the actual maps in one localization presentation.

`genericQuotientLift` is the native localization lift on a specified actual
localization, with target the single fixed `FractionRing R`.
`genericQuotientMap` specializes that constructor to the original generic
ring. For surjective `f`, it is surjective and its kernel is the
native maximal ideal; `genericResidueFieldEquiv` identifies the actual
residue field with `FractionRing R` and retains the original quotient map.
`genericQuotientMap_comp_of_base` proves compatibility for a commuting square
of ring homomorphisms between arbitrary source rings and the shared quotient.
The actual new generic quotient map is fixed as `arcGenericQuotientMap`,
using the same constructor on `arcLocalMap` and its actual generic source
with the shared localization instance.
`genericQuotientMap_comp_arcGenericEquiv` specializes the general compatibility
result to the constructed generic comparison and these original quotient maps.
Since surjectivity of the latter was already derived, both residue-field
identifications use the same original quotient `R`.

The generic comparison needs `R` to be a local domain and `f t ≠ 0`.
Under the original target's domain hypothesis on `C`,
`arcGenericLocalRing_isDomain` derives domainness of the new generic ring.
`arcGenericLocalRing_isDiscreteValuationRing` installs that derived domain
proof inside its conclusion and transfers the given DVR structure on the
original `C_p` through the constructed equivalence.
No regularity or generic-comparison premise on the blowup is assumed.

`exists_minimal_kernel_generators_generic_uniformizer` constructs a finite
kernel generating set with cardinality exactly the native `spanFinrank` and
a distinguished original member uniformizing the given generic DVR. A finite
family in a valuation ring has a member generating its whole ideal; applying
this to the original generators in `C_p` selects that member. The same theorem
proves that every selected generator remains outside the ideal generated by
the others together with `p²`: Nakayama would otherwise remove it, contradicting
the minimum cardinality.

`exists_unit_pow_mod_ker` uses the actual surjection onto the original DVR to
lift the unit in its uniformizer factorization. `exists_power_relation_of_generic_span`
clears a genuine localization denominator from `p C_p = (z₁)` and uses that
unit lift to obtain `tⁿ z − a z₁ ∈ p²`. Its kernel error is absorbed in `p²`.
Thus existence of an individual torsion relation is proved directly, without
assuming a finite-module torsion oracle.

`exists_positive_normalized_relation` proves the normalized one-term or
unit-times-power relation with all displayed exponents positive, from
independence of the two generators modulo `p²`.
`exists_positive_relation_of_minimal_kernel_generators` supplies that
independence by the actual minimum-cardinality generating set and Nakayama.
Its output feeds the existing literal division-by-`t²` theorems.

`arcChart_isDomain` and `arcLocalRing_isDomain` preserve domainness on the
actual chart and closed-point localization. `spanFinrank_ker_arcLocalMap_le`
constructs a divided finite generating family for the actual new kernel and
proves that its intrinsic minimal generator count cannot increase. It assumes
no count decrease. `isRegularLocalRing_of_ker_eq_span` proves the principal-kernel
stopping case when the source has actual dimension two, using the same
surjection, uniformizer, and derived maximal-ideal equations.

This module supplies algebraic prerequisites for the actual arc steps, not full R.D3.
Dimension preservation, strict count drop when a transformed exponent reaches
zero, preservation of a selected divided generic uniformizer, minimization of
the exponent over actual minimal generating data, strict lexicographic decrease,
and assembly of the finite chain ending in a regular local ring remain outside
its statements. The generic prerequisites retain the given original generic
DVR; conversion from the regular-generic-local-ring formulation requires its
surface height-one argument. No RDP classification or chart claim is imported.
