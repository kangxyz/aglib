# Formal smoothness of an arbitrary field over a perfect field

`Algebra.FormallySmooth.field_of_perfectField` proves that every field K
over a perfect field F is formally smooth over F. There is no finite-type,
finite-transcendence-degree, perfectness-of-K, or finite p-basis hypothesis.
The original `Algebra F K` action is retained.

The more general supplier
`of_formallySmooth_finitelyGenerated_subfields` assumes that every actual
finitely generated intermediate field is formally smooth and derives formal
smoothness of K. The perfect-base theorem discharges this premise using
Mathlib's existing `Algebra.FormallySmooth.of_perfectField` instance on each
such finite-type intermediate field.

The proof uses the canonical polynomial presentation

```text
P = F[X_a | a ∈ K] → K,   X_a ↦ a,
J = ker(P → K).
```

Mathlib's formal-smoothness definition asks for projectivity of Ω[K/F] and
vanishing of the first cotangent homology. Projectivity is automatic over
the field K. A class in the kernel of `J/J² → ⊕_a K dX_a` has a polynomial
representative f in J. Its kernel condition says that every partial
derivative of f evaluates to zero in K.

Let `L = IntermediateField.adjoin F (f.vars : Set K)`. This is the actual
subfield of K generated by the finite variable support of f. Native
renaming gives `g ∈ F[X_l | l ∈ L]` whose image under the literal subtype
renaming L → K is f. Evaluation of g vanishes in L because its image in K
does. The same applies to each evaluated partial derivative: differentiation
commutes with this injective renaming, and the subtype field map is
injective.

The field L is formally smooth by the finite-subfield hypothesis. Hence
its canonical cotangent-complex map is injective. The class of g has zero
differential, so `g ∈ J_L²`. Renaming maps J_L into J and consequently maps
J_L² into J². Therefore `f ∈ J²`, and the original cotangent class is zero.
This proves the full first-homology vanishing without a general theorem
about preservation of formal smoothness under filtered colimits.

The mathematical source is the finite-subextension argument of
[Stacks, Lemma 10.158.7 (0320)](https://stacks.math.columbia.edu/tag/0320).
That proof passes first cotangent homology through a filtered colimit; this
implementation instead descends each representative through its actual
finite variable support. The canonical presentation, cotangent basis,
partial-derivative formula, and relation-square criterion are native
Mathlib objects. The finite-support descent above is new proof work and
has its own mathematical review boundary.

The current consumer is
[`LocalRing/CoefficientSection`](../LocalRing/CoefficientSection.lean).
For a prime p, the coefficient field `ZMod p` is perfect, so this theorem
permits an arbitrary, possibly imperfect actual residue field. It does not
construct an arbitrary-residue mixed-characteristic Cohen ring or its
embedding into a given complete local ring.
