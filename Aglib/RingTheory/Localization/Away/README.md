# Principal localization formulas

`MapInverse` proves unit and homomorphism formulas for the actual distinguished
inverse. `Products` constructs the explicit product algebra and localization,
its algebra equivalence and the finite pointwise product instance. All base
rings and algebra structures remain the displayed ones.

`SaturatedChart` is the actual subalgebra generated by ideal fractions in
`Localization.Away a`; its spanning bound and fraction identities require no
geometric blowup identification. The inverse-map formula is shared with
`MapInverse`. The source abbreviation for a Laurent localization simply reuses
`Localization.Away (Polynomial.X : R[X])`; there is no second Laurent object.

Focused interface guides: [Unique lifts from the actual saturated chart](SaturatedChartLift.md).

[Torsion](Torsion.lean) uses the native kernel of `R → Localization.Away p` to remove exactly
`p`-power torsion. It constructs and characterizes the quotient lift to a target
where the image of `p` is regular, and proves that the image of `p` in this actual
quotient is regular. `NeronModification.Basic` consumes this generic supplier.
