# Local cotangent surjectivity and generic etaleness

`LocalCotangent.lean` proves a local algebra criterion using the original
`Ideal.mapCotangent` and `IsLocalRing.ResidueField.map` of the given homomorphism.
For a local `k`-algebra map `f : R →ₐ[k] S`, with `S` Noetherian, surjectivity
of the actual cotangent map implies

```text
(IsLocalRing.maximalIdeal R).map f.toRingHom = IsLocalRing.maximalIdeal S.
```

The proof forms the submodule of the target maximal ideal generated by the
actual image of the source maximal ideal. Its image in the target cotangent
quotient is all of that quotient. The native local Nakayama theorem
`IsLocalRing.CotangentSpace.map_eq_top_iff` therefore makes the submodule the
whole maximal ideal.

If `f` is essentially finite type and its actual residue-field map is also
surjective, `formallyUnramified_of_surjective_mapCotangent` proves that `f` is
formally unramified. The residue map is a field isomorphism and hence separable;
the proved maximal-ideal equality then applies
`Algebra.FormallyUnramified.of_map_maximalIdeal`. The base `k` need only be a
commutative ring for these algebra lemmas. Source and target universes remain
independent, and source Noetherianity is not assumed.

The second interface concerns an actual commutative square

```text
R --f--> S
| i      | algebraMap S L
v        v
K --g--> L,
```

where `K` and `L` are fields, `L` is the fraction ring of `S`, `f` is formally
unramified, and the original `g` is finite. Localization and composition make
`g.comp i` formally unramified, and restriction of scalars gives formal
unramifiedness of `g`. The native field criterion then proves formal etaleness
of the same `g`. No identification with a replacement field embedding occurs.

The current consumer is `AlgebraicGeometry/Group/MultiplicationInvertible.lean`.
There the actual rational-point residue map is proved to be identity and the
actual cotangent map is proved to be an invertible scalar. The generic square
is the original scheme stalk-specialization square. The only finite algebra
used at the last step is the actual generic-field extension; neither finite
presentation nor module-finiteness of a localized identity stalk is asserted.
