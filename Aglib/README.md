# Aglib mathematical families

`Aglib` is the import root. Declarations extend native mathematical owners; module identities follow the source tree and need not coincide with declaration namespaces.

| Family | Objects and principal results |
| --- | --- |
| [KTheory/MilnorK](KTheory/MilnorK/README.md) | All-degree field-symbol groups, low-degree comparisons, products and residues; finite-extension norms retain characteristic zero |
| [FieldTheory](FieldTheory/README.md) | Finite-extension, rational-function, root-field and Galois prerequisites |
| [Analysis/Normed/Field](Analysis/Normed/Field/README.md) | Small-norm consequences for actual cyclic unit quotients and their descended periods |
| [Data](Data/README.md) | Elementary finite-index and interval operations used by algebraic constructions |
| [RingTheory](RingTheory/README.md) | Effective algebra descent, regular-local domain/normality, fibrewise regularity, Fitting ideals, generic freeness, Grassmannian descent interfaces, support/length and norm prerequisites |
| [Algebra](Algebra/README.md) | Finite-module scalar/localization interfaces, exactness, cones, total complexes, derived coinduction, Koszul Ext and finite-projective cohomology models |
| [LinearAlgebra](LinearAlgebra/README.md) | Tensor-map injectivity, multilinear span transport, semilinear exterior powers, determinant interfaces and dependent sums |
| [CategoryTheory](CategoryTheory/README.md) | Selected exact structures, abelian subcategories, small models, resolution/Ext and derived comparisons, monoidal interfaces and site descent/Cech theory |
| [Topology](Topology/README.md) | Actual sheaf sections, basis detection, Mayer–Vietoris and Noetherian topological support |
| [AlgebraicGeometry](AlgebraicGeometry/README.md) | Scheme modules and descent, curves and relative Picard objects, actual stalk and Cartier geometry, qcqs flat base change, proper coherent cohomology and projective-space duality |

Each occupied subfamily records its objects, focused imports, canonical maps, main results and exact conditions. [Root documentation](../docs/README.md) coordinates reading routes, scope and evidence. Use `import Aglib` for the aggregate; implementations import precise lower leaves.
