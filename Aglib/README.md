# Aglib mathematical families

`Aglib` is the import root. Declarations extend native mathematical owners; module identities follow the source tree and need not coincide with declaration namespaces.

| Family | Objects and principal results |
| --- | --- |
| [RingTheory](RingTheory/README.md) | Effective algebra descent, regular-local domain/normality, fibrewise regularity, tensor domains, support, filtration and localized-length/Euler results |
| [Algebra](Algebra/README.md) | Finite-module scalar/localization interfaces, exactness, cones, total complexes, derived coinduction and finite-projective cohomology models |
| [LinearAlgebra](LinearAlgebra/README.md) | Tensor-product maps and transported injectivity, semilinear exterior powers and determinant interfaces |
| [CategoryTheory](CategoryTheory/README.md) | Selected exact structures, abelian subcategories, small-model transport, resolution/Ext comparisons and generic Cech and derived-category interfaces |
| [Topology](Topology/README.md) | Actual sheaf sections, basis detection, Mayer–Vietoris and Noetherian topological support |
| [AlgebraicGeometry](AlgebraicGeometry/README.md) | Scheme modules, properties/morphisms, ordinary Picard objects, qcqs flat base change, Noetherian proper finiteness/models and projective-space duality |

Each occupied subfamily records its objects, focused imports, canonical maps, main results and exact conditions. [Root documentation](../doc/README.md) coordinates reading routes, scope and evidence. Use `import Aglib` for the aggregate; implementations import precise lower leaves.
