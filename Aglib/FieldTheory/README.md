# Field-theoretic prerequisites

The native owners are `AdjoinRoot`, `IntermediateField`, `Polynomial`,
`RatFunc`, `Algebra` and their actual maps. The selected leaves construct
root-field coefficient and branch comparisons, coprime splitting fields,
Sylow fixed-field embeddings and rational-function coefficient, inversion,
translation and reverse-polynomial maps.

They preserve irreducibility, normality, separability, finite-dimensional and
scalar-tower hypotheses. Milnor norm proofs consume these algebraic interfaces;
no Milnor quotient or motivic comparison is defined by this family.
