# Scalar-kernel comparisons

`Kernels.lean` constructs scalar kernels, their lifts and the product comparison
on the original index type. `ProductReindex.lean` applies the actual additive
left exact functors to the original value kernels, constructs the whole product
isomorphism, and identifies it with the original reindexed comparison through
kernel inclusions and product projections. All moduli, including zero and one,
are retained.
